# Academic English Style Guide

This note records the shared academic-English style for Gaia and TA_YK when preparing manuscripts, research documents, reviewer responses, and teaching materials for Piakman.

Hermes skill created on Gaia:

```text
academic-english-writing
```

## Default style

Use clear, precise, restrained academic English. The text should sound scholarly but not inflated.

Preferred qualities:

- clear main claim
- precise technical nouns and verbs
- appropriate hedging
- evidence-based statements
- consistent terminology
- concise transitions
- no invented citations, numbers, methods, or conclusions

Avoid:

- promotional language
- generic AI-sounding filler
- overclaiming clinical or causal implications
- vague novelty claims
- unsupported significance claims
- decorative emphasis, emojis, and excessive boldface

## Useful academic verbs

Prefer verbs such as:

```text
measured, estimated, computed, compared, evaluated, validated, quantified,
increased, decreased, was associated with, was consistent with, may contribute to
```

Use carefully:

```text
demonstrates, proves, confirms, establishes
```

Only use these when the evidence directly supports the strength of the claim.

## Domain wording for Piakman's work

Preferred terminology:

- hemodynamics
- velocity field
- flow rate
- wall shear stress
- pressure gradient
- vortex formation
- energy loss
- regurgitant fraction
- peak velocity
- stroke volume
- patient-specific geometry
- boundary conditions
- computational fluid dynamics (CFD)
- 4D flow MRI / time-resolved three-directional phase-contrast MRI

Clinical caution:

- Prefer `may help characterize` over `can diagnose`.
- Prefer `is associated with` over `causes`.
- Prefer `supports further investigation` over `establishes clinical utility`.

## Teaching documents

For lecture notes and teaching documents:

- define key terms before equations or standards
- use examples connected to engineering practice
- keep terminology consistent across slides, notes, and exercises
- use concise headings
- avoid overfilled paragraphs
- use `Students should be able to...` for learning outcomes
- when adapting standards, cite the standard and do not present simplified rules as the full standard

## Reviewer response tone

Useful response patterns:

```text
We thank the reviewer for this helpful comment.
We agree that this point required clarification.
We have revised the manuscript to clarify ...
The revised text now reads: "..."
We have added ... to address this concern.
Although ..., we acknowledge that ... and have added this limitation.
```

## Anti-AI academic checklist

Before finalizing, remove or revise:

- plays a crucial role
- serves as a foundation/testament
- underscores/highlights the importance
- delves into
- complex interplay
- intricate relationship
- robust and comprehensive
- in the ever-evolving landscape
- it is important to note that
- formulaic `not only... but also...`
- vague `future research is needed` without a specific next step
- unsupported novelty, significance, or clinical-impact claims

## Workflow for TA_YK / Gaia

When asked to write academic English:

1. Identify the genre: manuscript, abstract, reviewer response, thesis/report, teaching note, or email.
2. Preserve technical meaning before polishing style.
3. Do not invent missing data.
4. Mark uncertain factual claims as `[verify]`.
5. Separate results from interpretation.
6. Return polished English first, then short notes if useful.
